# هزینه‌های اداره

اپلیکیشن React برای ثبت هزینه‌های مشترک اداره. داده‌ها در یک فایل JSON انتخابی شما ذخیره می‌شوند و برنامه به سرور یا حساب کاربری نیاز ندارد.

## اجرا

1. `npm install`
2. `npm run build`
3. فایل `dist/index.html` را با نسخهٔ جدید Chrome یا Edge باز کنید.
4. در برنامه «فایل جدید» را بزنید و محل ذخیرهٔ فایل JSON را انتخاب کنید، یا یک فایل قبلی را باز کنید.

## انتشار در GitHub Pages

پس از ساخت مخزن Git و تنظیم remote به نام `origin` روی مخزن GitHub، دستور `npm run deploy` برنامه را می‌سازد و محتوای `dist` را با `angular-cli-ghpages` به شاخهٔ `gh-pages` می‌فرستد. در تنظیمات GitHub Pages مخزن، شاخهٔ `gh-pages` را به‌عنوان منبع انتشار انتخاب کنید. این پروژه React است؛ بنابراین دستور `ng deploy` برای آن کاربرد ندارد.

پس از انتخاب فایل، هر تغییر به همان فایل ذخیره می‌شود. برای باز شدن خودکار در اجراهای بعدی، «تنظیم فایل فعلی به‌عنوان پیش‌فرض» را بزنید. مرورگر ممکن است در اجرای بعدی دوباره اجازهٔ دسترسی به فایل را بخواهد؛ در این صورت «اتصال به فایل پیش‌فرض» را بزنید. API دسترسی مستقیم به فایل در مرورگرهای دیگر ممکن است پشتیبانی نشود.

برای ثبت یا ویرایش عنوان، روی نوشتهٔ عنوان فایل کلیک کنید. عنوان در خود فایل JSON ذخیره می‌شود. فایل‌های قدیمی بدون عنوان نیز باز می‌شوند.

«کپی از فایل فعلی» یک JSON جدید با عنوان انتخابی، همان نفرات و کالاها، و فهرست هزینه‌ها و تسویه‌های خالی می‌سازد. فایل اصلی دست‌نخورده می‌ماند و برنامه پس از ساخت، فایل جدید را باز می‌کند.

جمله‌های نوار پایین صفحه از آرایهٔ `tickerMessages` همان فایل JSON خوانده می‌شوند. پس از باز شدن فایل، یکی به‌صورت تصادفی نمایش داده می‌شود، از چپ به راست حرکت می‌کند و پس از ۱۰ ثانیه از صفحه حذف می‌شود. رابط برنامه امکان ویرایش یا حذف جمله‌ها را ندارد. هنگام باز شدن فایل قدیمیِ بدون این آرایه، برنامه جمله‌های پیش‌فرض را به خود فایل اضافه می‌کند.

ماندهٔ هر نفر برابر است با مجموع پرداخت‌های او منهای سهمش از هزینه‌ها. هنگام ثبت هر هزینه، افراد شریک آن هزینه مشخص می‌شوند (به طور پیش‌فرض همهٔ افراد فعلی). این فهرست در همان هزینه ذخیره می‌شود، پس افزودن فرد جدید سهم هزینه‌های قدیمی را تغییر نمی‌دهد. مبلغ‌ها و مانده‌ها بر حسب تومان هستند.
در نمای کلی، پیشنهاد تسویه نشان می‌دهد چه کسی چه مبلغی را به چه کسی بدهد. سهم‌ها به تومان صحیح محاسبه می‌شوند؛ اگر مبلغ هزینه بر تعداد افراد بخش‌پذیر نباشد، تومان‌های باقی‌مانده به ترتیب فهرست افراد شریک تقسیم می‌شوند.
برای هر نفر با ماندهٔ غیرصفر یا از کنار پیشنهاد تسویه می‌توان پرداخت واقعی را ثبت کرد. مبلغ می‌تواند بخشی از مانده باشد. تسویه‌های ثبت‌شده در تب «تسویه‌ها» دیده و در صورت اشتباه حذف می‌شوند؛ مانده‌ها پس از هر تغییر دوباره محاسبه می‌شوند.

برای هر هزینه، تعداد کالای خریداری‌شده و مبلغ کل پرداختی ثبت می‌شود. فایل‌های JSON قدیمی که فیلد تعداد ندارند با تعداد پیش‌فرض ۱ باز می‌شوند.

تاریخ هزینه را به صورت شمسی و با قالب `۱۴۰۵/۰۷/۱۳` وارد کنید. تاریخ‌های قدیمی هنگام ویرایش به همین قالب نمایش داده می‌شوند. انتخاب تم روشن یا تیره در همین مرورگر حفظ می‌شود.

در صفحهٔ هزینه‌ها، پرداخت‌ها بر اساس روز شمسی از جدید به قدیم گروه‌بندی می‌شوند و مجموع هزینهٔ هر روز کنار تاریخ آن نمایش داده می‌شود.
در نمای کلی، مجموع هزینه‌های ثبت‌شده برای هر کالا نیز نمایش داده می‌شود.

فونت متن برنامه «وزیر» است و همراه نسخهٔ ساخته‌شده برای استفادهٔ آفلاین قرار می‌گیرد.
